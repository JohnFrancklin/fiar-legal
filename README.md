# fiar-legal

Documents légaux publics de l'application **Taxi Fianar** (FIAR), publiés via
GitHub Pages car la Play Console exige des URL publiques.

| Document | URL |
| --- | --- |
| Politique de confidentialité | <https://johnfrancklin.github.io/fiar-legal/> |
| Suppression de compte | <https://johnfrancklin.github.io/fiar-legal/suppression-compte/> |

## Source

Ces pages sont publiées automatiquement depuis `main` par GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `root`).

Le contenu doit rester **synchronisé avec l'application** : toute évolution des
données collectées (nouvelle fonctionnalité, nouveau champ, nouvelle permission)
doit être répercutée ici **et** dans le formulaire *Sécurité des données* de la
Play Console.

## Modifier

Éditer `index.md` ou `suppression-compte.md`, mettre à jour la date en tête de
page, puis pousser sur `main`. Le site est reconstruit en une à deux minutes.

## Contact

Le contenu renvoie à `contact@fiar.mg`. Si cette adresse change, la mettre à
jour dans les deux fichiers.
